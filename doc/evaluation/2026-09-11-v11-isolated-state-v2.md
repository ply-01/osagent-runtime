# 银河麒麟 V11：480 条新版自然语言状态评测

## 最新结果

在银河麒麟 V11 虚拟机实际执行全部 480 条未向实现者公开的样例，按 `natural-conflict-state-v2-draft1` 评分，**221 条正确、259 条不符，正确率 46.04%**。自动标注复核覆盖 480/480，无缺失预测或待复核项。旧协议同集合为 100/480（20.83%）。

此次更新的是评分基线，不是算法提升。两套评分判定对象不同，不能据其差值宣称提升；也不能与已查看开发 20 条的 65% 直接比较。当前 v2 仍是草案、标注是自动复核而非人工金标准。

## 独立标注流程

1. 排除固定种子 20260910 抽取并已查看的 20 条，剩余 480 条由程序处理，实现者不查看内容。
2. `deepseek-v4-flash` 每条进行两次独立调用，只收到自然语言输入、所有者约定和评测属性词表，不收到被测输出或参考答案，调用之间不共享答案。
3. 验证值与作用域确实出现在输入中；比较两次标注结果，并与原标签在评测层迁移后的状态核对。
4. 三者一致才接受，否则保留争议状态、不计作已复核。此次 480 条全部一致。
5. 标注冻结后同步 V11；被测 rules 先预测全部 480 条，再由评分阶段读取标签。测试数据未写入在线用户记忆。

这是同一模型的重复标注，不是两个独立模型或人工复核。模型可能共享偏差，原参考标签也可能有系统性错误，因此一致性不能等同于绝对真值。评测词表来自已授权开发标注，位于 benchmarks，不调用生产解析器生成答案，不进入生产实现。
